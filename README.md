## Project Structure

- `src/main/java` - Java application code
- `src/main/resources/templates` - HTML templates
- `src/main/resources/static/css` - CSS styles
- `src/main/resources/static/js` - JavaScript files
- `src/test/java` - Application tests
## How to Run the Project

1. Clone this repository.
2. Open the project in an IDE such as IntelliJ IDEA.
3. Configure the database settings in `application.properties`.
4. Install the required Maven dependencies.
5. Run `ShaliniSmartMartApplication.java`.
6. Open `http://localhost:8080` in your browser.

## Testing

Automated tests are available in the `src/test/java` directory.

Run the tests using Maven:

`mvn test`
